# Transformative Education Diagnostic Tool

A self-assessment tool for educators in health professions education at Karolinska Institutet. It covers eight principles of transformative education. Rate how often each statement describes your current teaching practice, then get a radar diagram of your scores with CAN-DO statements and teaching activity examples for each principle.

## Live site

[amnaaldaraji.github.io/transformative-education](https://amnaaldaraji.github.io/transformative-education)

## How it works

1. Accept the GDPR consent and enter your course code
2. Rate 5 statements per principle on a scale from Never to Very Often (N/A available)
3. After all 8 principles are complete, a radar diagram and colour-coded scores appear
4. Expand each principle to read CAN-DO statements and teaching examples matched to your level
5. Send your results directly to the research team via the send button

## Built with

- Plain HTML, CSS and vanilla JavaScript (no framework, no build step, single file)
- Chart.js for the radar diagram
- EmailJS for sending results
- Hosted on GitHub Pages

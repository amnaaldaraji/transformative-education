# Transformative Education Diagnostic Tool

A self-assessment tool for educators in health professions education at Karolinska Institutet. Covers eight principles of transformative education — rate your current teaching practice, get a radar diagram of your results, and explore CAN-DO statements and teaching examples for each principle.

Built as a single HTML file. No framework, no build step.

## Usage

Open `index.html` in a browser or visit the live site:
**[amnaaldaraji.github.io/transformative-education](https://amnaaldaraji.github.io/transformative-education)**
